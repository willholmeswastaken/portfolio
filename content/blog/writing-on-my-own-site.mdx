I've been publishing on Hashnode and dev.to for a while, but I wanted a place to write that's fully mine — no platform chrome, no algorithm, just words on a page I control.

This site now supports **MDX blog posts**: Markdown files with optional React components mixed in. Drop a `.mdx` file in `content/blog/`, add some frontmatter, and it shows up here.

## How it works

Each post is a file like this:

```mdx
---
title: "My post title"
description: "A short summary for listings and SEO."
publishedAt: "2026-06-29"
---

Your content here. Markdown works as usual.

<Callout title="Pro tip" variant="accent">
  You can drop in React components whenever you want something nicer than plain text.
</Callout>
```

The frontmatter drives the title, description, and date on the blog index and homepage. The body is rendered as MDX, so you get headings, code blocks, links — and components like the callout below.

<Callout title="MDX in action" variant="accent">
  This orange box is a React component imported into the post. Handy for asides, warnings, or anything that needs a bit more structure than a blockquote.
</Callout>
